# Administre su instancia de Adobe Workfront Planning como producto independiente

>[!IMPORTANT]
>
>La información de este artículo hace referencia a Adobe Workfront Planning, cuando se compra como producto independiente. Consulte este artículo cuando su empresa haya adquirido un paquete exclusivo de Adobe Workfront Planning y no un paquete de flujo de trabajo de Workfront.
>
>Para obtener información acerca de Adobe Workfront Planning cuando se adquiere junto con un paquete de Workfront, consulte [Introducción a Adobe Workfront Planning](/help/quicksilver/planning/general/planning-overview.md).

Como administrador de Workfront Planning, puede administrar su instancia de Adobe Workfront Planning.

Puede configurar las siguientes opciones para Workfront Planning:

* Trimestres personalizados
* Inform. de cliente
* Preferencias
* Equipos

  Para obtener más información, consulte [Administrar equipos en Adobe Workfront Planning como producto independiente](/help/quicksilver/planning/planning-sta/manage-teams-in-planning-sta.md).
* Usuarios

  Para obtener más información, consulte [Administrar usuarios en Adobe Workfront Planning como producto independiente](/help/quicksilver/planning/planning-sta/manage-users-in-planning-sta.md).

La configuración de Workfront Planning como producto independiente es similar a la configuración de algunas de las opciones de Adobe Workfront. Sin embargo, existen limitaciones en cuanto a la información disponible en Workfront Planning.

## Iniciar sesión como otro usuario

Como administrador de Planning, puede iniciar sesión como otro usuario para solucionar problemas. Iniciar sesión como otro usuario en Workfront Planning es similar a iniciar sesión como otro usuario en Workfront.

Para obtener más información, consulte [Iniciar sesión como otro usuario](/help/quicksilver/administration-and-setup/add-users/create-and-manage-users/log-in-as-another-user.md).

## Configuración de trimestres personalizados

Es posible que desee crear trimestres personalizados si los trimestres de su organización se basan en criterios específicos distintos de las fechas del calendario (como días laborables o días de compras).

Puede configurar hasta 100 trimestres para la instancia de Workfront Planning. Puede utilizar estos trimestres personalizados en la vista de cronología.

La configuración de trimestres personalizados en Workfront Planning es similar a la configuración de trimestres personalizados en Workfront.

Para obtener más información, consulte [Habilitar trimestres personalizados](/help/quicksilver/administration-and-setup/set-up-workfront/configure-system-defaults/enable-custom-quarters-projects.md).

## Configurar la información del cliente

Como parte de la configuración del producto de Adobe Workfront Planning, puede administrar los detalles sobre su organización en la sección Información del cliente de Configuración.

La configuración de la sección Información del cliente en Workfront Planning es similar a la configuración en Workfront.

Para obtener más información, consulte [Configurar información básica para el sistema](/help/quicksilver/administration-and-setup/get-started-wf-administration/configure-basic-info.md).


## Configure las preferencias de su sistema

Como administrador de Planning, puede configurar las preferencias de su sistema de Workfront Planning.

Los cambios que realice en el área Preferencias del sistema de Configuración afectan a todos los usuarios del sistema y a su experiencia en Workfront Planning.

Le recomendamos que configure las preferencias del sistema durante la Workfront Planning como implementación de producto independiente y que solo las vuelva a consultar ocasionalmente después de dicha implementación.

Configurar las preferencias del sistema de Workfront Planning es similar a configurarlas en Workfront.

Para obtener más información, consulte [Configurar las preferencias del sistema](/help/quicksilver/administration-and-setup/manage-workfront/security/configure-security-preferences.md).
