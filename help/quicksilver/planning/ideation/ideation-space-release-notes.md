# Espacio de ideación para la actividad de la versión de Adobe Workfront Planning

<span class="preview">La información de esta página hace referencia a una funcionalidad que aún no está disponible de forma general. Solo está disponible como parte del programa **Beta** del espacio de ideación. </span>

<span class="preview">Para obtener más información, consulte [Introducción al espacio de ideación para Adobe Workfront Planning](/help/quicksilver/planning/ideation/get-started-with-planning-ideation.md).</span>

Este artículo describe las características que se están lanzando para el espacio de ideación de Workfront Planning durante el período **Beta del espacio de ideación**. El espacio Abrir Beta para ideación está programado para ejecutarse entre el 12 de noviembre de 2026 y el 1 de febrero de 2027.

Para las versiones de Adobe Workfront Planning, consulte [Actividad de la versión de Adobe Workfront Planning: índice de artículo](/help/quicksilver/product-announcements/product-releases/planning-release-activity/planning-release-activity-article-index.md).

## Nueva área de inicio para el espacio de ideación en Adobe Workfront Planning

>[!NOTE]
>
>Disponible para entornos de vista previa y producción para clientes de Ideation Space beta: 25 de noviembre de 2026

Al acceder al espacio de ideación desde el menú de waffles de Workfront, ahora se abre el área de inicio del espacio de ideación. Desde aquí, puede volver a abrir un lienzo existente o crear uno, por lo que ya no necesita comenzar con un lienzo en blanco para llegar a uno existente. El área de Inicio muestra los lienzos recientes como mosaicos, enumera todos los demás lienzos de la parte inferior de la pantalla e incluye un cuadro de búsqueda. Cuando esté trabajando dentro de un lienzo, utilice el nuevo botón Inicio para volver al área de Inicio del espacio de ideación.

Para obtener más información, consulte [Crear informes en el espacio de ideación](/help/quicksilver/planning/ideation/create-briefs-in-ideation-space.md).
